## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## Razorpay payments

Set `RAZORPAY_KEY_ID` and `RAZORPAY_KEY_SECRET` in `.env.local` for local development and in the deployment environment (for example, Vercel project settings). Use Razorpay test-mode credentials while testing. Keep the key secret server-side; only the key ID is sent to the browser. Checkout creates a fixed ₹299 INR order, verifies Razorpay's payment signature on the server, and redirects to Google after verification.
